# Invito a pranzo

Pagina statica pronta per GitHub Pages.

## Pubblicazione rapida

1. Crea un nuovo repository su GitHub.
2. Carica il contenuto di questa cartella (inclusi `index.html`, `style.css` e `script.js`).
3. In **Settings → Pages**, scegli **Deploy from a branch**, poi la branch `main` e la cartella `/(root)`.

GitHub fornirà l'indirizzo pubblico della pagina entro pochi minuti.

La foto del ristorante è caricata dal sito ufficiale della Locanda al Greto; i due link finali conducono rispettivamente a Google Maps e al sito del locale.
